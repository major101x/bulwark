# Project conventions

## Writing

- **No em-dashes.** Not in code comments, docs, commit messages, or chat replies.
  Use a comma, a colon, parentheses, or split the sentence. This applies to en-dashes
  used as punctuation too; ranges like `1-5` are fine.

## Git

- **Small commits.** One logical change per commit. Prefer several focused commits
  over a single large one, and commit as work completes rather than batching up.
